_Last updated: 2026-06-16_

## Tech Stack
| Layer | Technology | Notes |
|-------|------------|-------|
| Frontend | Vanilla HTML/CSS/JS | No frameworks |
| Hosting | GitHub Pages | Served from main branch root |
| Data | GitHub Contents API | Reads .md files from public repos |

## Architecture
Single static index.html. On load, fetches `2. Project Overview.md` and
`3. Work Packages.md` from each registered repo via GitHub API. Parses
markdown content client-side to extract status, summary, and checkbox counts.

## Key Patterns
- GitHub API endpoint: `https://api.github.com/repos/zowen22/{repo}/contents/{path}`
- Response is base64 encoded — decode with `atob()`
- Progress: count `- [x]` vs total `- [ ]` and `- [x]` lines in Work Packages.md
- Status: parse `Planning` / `In Progress` / `Complete` from Project Overview.md

## Project Registry
Registered repos are maintained as a simple array at the top of index.html.
**This list does not auto-update — a new repo won't appear on the dashboard
until it's added here manually.** Private repos can never load: the fetch
is unauthenticated client-side JS on a public GitHub Pages site, so there's
no token to read a private repo without exposing it to the world.
```js
const PROJECTS = [
  "X.-Claude-Project-Dashboard",
  // add new projects here
];
```

## Responsive Layout
Mobile-first, three tiers:
- **<541px (mobile):** 2-column compact grid, cards show name, status dot, up to 2 next steps (2-line clamp), progress bar.
- **541–999px (tablet):** auto-fill grid (min 260px cols), same compact card.
- **≥1000px (desktop):** auto-fill grid (min 340px cols), max-width 1440px. Cards add: project summary (parsed from Overview's `## Summary` section, 3-line clamp), up to 5 next steps (3-line clamp each), and last-pushed relative date. All extra content lives in the DOM already (fetched once) and is toggled via CSS media queries — no extra fetches per breakpoint.
